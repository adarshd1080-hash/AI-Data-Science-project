# Algorithm: Mood & Emotion Based Music Recommendation System

Step 1: Start the application.

Step 2: Load the cleaned music dataset.

Step 3: Display the home page.

Step 4: User chooses one of the following:
- AI Chatbot
- Explore Music

Step 5: If AI Chatbot is selected:
- Accept user input.
- Detect the user's mood.
- Map the mood to suitable genres.
- Search the dataset.
- Recommend the top matching songs.

Step 6: If Explore Music is selected:
- Accept filters.
- Search the dataset.
- Display matching songs.

Step 7: User can view song details or save favorites.

Step 8: End.
